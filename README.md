# BRAiN — 제조기록서 반납 모니터링 (프로토타입)

화순공장 제조기록서 발행요청(G-net) → 발행(Veeva-EDMS) → 배포 → 작성완료 → 반납 흐름을
모니터링하고, 작성완료일로부터 5일 반납기한 임박/초과 부서에 알림 메일을 보내기 위한
Next.js 프로토타입입니다.

이 세션에서는 셸 실행 도구가 막혀 있어 `npm install` 등을 대신 실행할 수 없었습니다.
아래 명령을 로컬 터미널에서 직접 실행해 주세요.

## 1. 설치 및 초기 세팅

```bash
npm install
copy .env.example .env      # Windows PowerShell: Copy-Item .env.example .env
```

`.env` 파일을 열어 다음을 채워주세요.

- `SESSION_SECRET`: 아무 랜덤 문자열 (프로토타입은 실제로 서명에 쓰지는 않지만 자리 확보)
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`: 사내 메일 서버 정보.
  **비워두면 메일이 실제 발송되지 않고 콘솔에 로그만 남습니다** (안전한 기본값).

## 2. 데이터베이스 생성 + 시드 데이터

```bash
npm run db:push
npm run db:seed
```

`data/teams-2025.json`에 있는 화순공장 팀/파트(2025.01.03 개편 기준, 국문/영문)를 읽어
팀 테이블을 채우고, 팀별 샘플 담당자 2명, 그리고 데모용 제조기록서(발행요청~반납완료까지
다양한 상태)를 자동 생성합니다.

시드 후 기본 로그인 계정:

| 아이디 | 비밀번호 | 권한 |
|---|---|---|
| `admin` | `admin1234!` | 관리자 (팀/담당자/계정/기록 전체 관리) |
| `qa` | `qa1234!` | 일반 열람자 (샘플) |

## 3. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 http://localhost:3000 접속.

- `/` : 부서별 반납 현황 대시보드 (제조번호는 마스킹 처리)
- `/login` : 로그인 (로그인 시 열람 이력 기록)
- `/team/[teamId]` : 부서별 제조기록서 목록
- `/record/[id]` : 마스킹 해제된 상세 (로그인 필요, 열람 시 자동 로그 기록)
- `/admin` : 관리자 콘솔 (`admin` 계정으로 로그인 필요)
  - 팀/파트명 수정, 알림 수신자 등록, 로그인 계정 관리, 제조기록서 등록/수정,
    기한임박 메일 발송, 열람/발송 로그 조회

## 다음 단계로 고려할 것

- 현재 제조기록서 데이터는 관리자가 화면에서 직접 입력하는 구조입니다. 추후 G-net
  전자결재 API / Veeva-EDMS API 연동이 가능해지면 `admin/actions.ts`의 `createRecord`/
  `updateRecord` 호출부를 스케줄러 또는 웹훅으로 대체하면 됩니다.
- 실제 사내 SSO/본인인증 시스템이 있다면 `src/lib/auth.ts`의 아이디/비밀번호 로그인을
  해당 시스템 연동으로 교체하세요.
- 반납기한 임박 메일을 매일 자동 발송하려면 `sendTeamAlert` 서버 액션을 호출하는 배치
  스케줄러(예: Windows 작업 스케줄러, cron, 또는 Vercel Cron)를 추가하면 됩니다.
